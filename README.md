# 黎老师中文班

Thư mục này đã sẵn sàng để đăng lên GitHub Pages.

## Các tệp cần tải lên GitHub

- `index.html`: trang web chính.
- `supabase-config.js`: kết nối đăng nhập và lưu tiến độ với Supabase.

## Cách đăng

1. Tạo một repository mới trên GitHub.
2. Chọn **Add file → Upload files**.
3. Tải lên `index.html` và `supabase-config.js` ở thư mục này. Có thể tải thêm `README.md` nhưng không bắt buộc.
4. Nhấn **Commit changes**.
5. Vào **Settings → Pages**.
6. Chọn **Deploy from a branch**, nhánh **main**, thư mục **/(root)** rồi nhấn **Save**.
7. Chờ GitHub cung cấp địa chỉ website.

Không công khai Database password, Secret key, `service_role` key hoặc khóa bắt đầu bằng `sb_secret_`.
